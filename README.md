# Treino de lacunas

Cole um texto em Markdown e preencha as lacunas para decorar. A cada rodada, as palavras escondidas mudam, na porcentagem do nível escolhido. O modo "Termos-chave" esconde só o que está em negrito e em `código`.

Um único `index.html`, sem build nem dependências. O texto e o nível ficam salvos no navegador (`localStorage`) e nunca saem dele. O site usa Vercel Web Analytics e Speed Insights, que contam visitas e medem desempenho sem cookies.
